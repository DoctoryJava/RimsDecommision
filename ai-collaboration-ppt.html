🤖AI 承担

  • 编码实现：后端接口/实体/Mapper、前端页面/组件/样式
  • 数据库设计：表结构 + 16 个 Flyway 迁移
  • 查询/同步：SeaTunnel 同步、Spark SQL、字段/关联/下钻 SQL
  • 功能迭代：下钻、审计、CSV 导出、脱敏、科技感 UI
  • 排错修复：权限/排序内存/导出流/超时/大小统计等

🧑‍💻人承担

  • 需求与决策：定方案、选型（行内下钻 / Command 下拉 / JDK）
  • 环境配置：本地 SeaTunnel/Spark/JDK/DB、执行迁移
  • 真实数据：源库连接、同步、表统计核对
  • 测试反馈：复现报错、确认交互方向、端到端验收

🔁协作模式

  • 决策 → 实现 → 反馈 闭环：人定方向，AI 落地，人验证反馈
  • AI 负责“怎么写”（编码/设计/排错），人负责“为什么/对不对”
  • 环境与真实数据靠人：AI 给方案，人执行迁移、连接、核对
  • 迭代极快：一个需求往往一轮对话即可落地可用
