## 1. 文档说明

### 1.1 目的

本文档将 `task.csv` 中 **Phase2：能力优化与冷数据承接** 的 63 项功能需求转化为可执行计划。作为 Phase1（基础归档与查询，26 项）之后的**能力深化阶段**，Phase2 的核心是把 RIMS 从“一次性退役归档”升级为**面向在运系统冷数据、增量数据、多源异构数据的常态化接入与精细化治理平台**。

- 明确 Phase2 与 Phase1 的边界（Phase1 的批量全量 vs Phase2 的周期性/实时性）；
- 将 7 个功能模块、20 个业务场景、15+ 关键功能落到架构与接口；
- 提供研发、测试、运维可追溯的任务清单（`phase2_tasks.csv`）与里程碑。

### 1.2 术语

| 术语 | 说明 |
|------|------|
| 冷数据 | 在运系统中访问频率低、最后访问时间久远、但仍需归档的数据 |
| 热/冷分层 | 按访问频率将数据分层存储：热层（高性能）/ 冷层（低成本） |
| 增量同步 | 持续识别源库新增/变更（CDC）并同步至 RIMS |
| Legal Hold | 法律保留，涉诉/审计期间暂停删除 |
| 连接器 | 标准化的数据源连接模板（DB/文件/第三方工具） |
| 标签体系 | 多层级、可版本化的业务标签，支持规则自动生成 |
| 脱敏 | 字段级保护策略（规则配置→应用→预览→审计），与 UC MASK 联动 |

## 2. Phase2 整体目标与价值

### 2.1 一句话目标

> **在 Phase1 已实现“退役系统批量归档、基础可查”基础上，实现“在运系统冷数据周期性归档 + 增量数据实时同步 + 多源标准化接入 + 归档数据精细化治理 + 个性化高效检索 + 合规审批与灾备”，使 RIMS 成为企业级“温数据-冷数据”统一归档与利用平台。**

### 2.2 承接的业务痛点演进

| Phase1 已解决 | Phase2 新增痛点 | Phase2 解法 |
|---------------|-----------------|-------------|
| 退役系统一次性归档 | 在运系统低频冷数据持续膨胀，占用高性能存储 | 冷数据识别→周期性接入→分类归档→分层存储（模块2/4/3） |
| 手工映射规则 | 多源异构元数据不一致，检索困难 | 统一元数据模型 + 来源绑定 + 分类/标签/质量治理（模块2） |
| 全量批量 | 新增/变更数据需人工重复导入 | 数据库/文件增量同步 + 业务事件触发（模块2） |
| 基础三件套检索 | 业务人员需要多维组合、模糊全文、导出管控 | 高级检索、组合筛选、加密字段导出控制（模块5） |
| 固定页面 | 不同岗位个性化诉求 | 自定义布局/字段/视图/模板（模块5） |
| 明文/粗粒度权限 | 字段级敏感数据需脱敏且可审计 | 脱敏规则配置→手动选字段→策略应用→预览→日志（模块4/6） |
| 单点存储 | 需要备份、异地灾备与演练 | 备份管理、异地灾备、恢复演练（模块4） |
| 烟囱式对接 | 多系统重复开发对接 | 标准 DB/文件连接 + 集成标准 + 连接器模板库 + 监控审计（模块7） |
| 基础审计 | 权限过度、审批缺失、整改无闭环 | 权限审计复核、电子签名、整改四步闭环（模块6/8） |

### 2.3 成功度量

| 指标 | Phase2 目标 |
|------|-------------|
| 冷数据识别准确率 | ≥95%（与业务规则比对） |
| 增量同步延迟 | ≤5 分钟（P95） |
| 标签自动生成覆盖率 | ≥80% 归档记录 |
| 字段级脱敏策略生效准确率 | 100% |
| 备份恢复演练成功率 | 100%，RTO ≤4h |
| 高级检索 P95 | ≤2s（多维组合） |
| 连接器复用率 | ≥60% 同类系统 |
| 权限审计整改闭环率 | 100% |

## 3. 范围界定

### 3.1 Phase2 在范围内 (Must Have)

| 领域 | 包含能力（63 项） |
|------|-------------------|
| **统一接入与治理 (模块2, 12项)** | 统一元数据模型、来源系统绑定、冷数据识别与周期接入、标签体系/规则生成/分类优化、质量评分/补全、数据库/事件/文件增量 |
| **冷数据归档与生命周期 (模块3, 9项)** | 冷数据分类归档、生命周期（保留/Legal Hold）、删除/策略变更审批、标准对象转换、规则自动应用、校验、到期自动删除 |
| **存储与安全增强 (模块4, 9项)** | 冷热分层、存储策略优化、字段级脱敏 4 件套（规则/手动/应用/预览）、备份/异地/演练 |
| **检索与个性化 (模块5, 11项)** | 个性化 5 件套（布局/字段/条件复用/个人视图/模板）、高级检索 3 件套（组合/精准/全文）、导出 2 件套（加密控制/文档导出）、性能优化 |
| **合规深化 (模块6, 7项)** | 脱敏日志、权限审计、电子签名、整改闭环 4 步 |
| **集成标准化 (模块7, 9项)** | 标准 DB/文件连接、第三方工具适配、源编码规则、交互格式规范、系统接口、模板库、监控/日志 |
| **治理与运维 (模块8, 6项)** | 监控告警、稳定性保障、记录/字段级权限、申请/变更审批 |
