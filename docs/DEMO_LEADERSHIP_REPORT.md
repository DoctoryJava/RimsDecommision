## 二、快速 Demo 原则

1.  **重要功能全部演示**：用户指定的 6 大重点（迁移、元数据/搜索、附件预览、一对多列表、定期删除、日志追踪）**全部为 P0**，额外补充 4 项（报表、权限、仪表盘）形成闭环。
2.  **AI 做脏活累活，人工做判断**：AI 自动完成探测/推荐/生成/校验，人工只做“确认/选择/触发”—— 降低演示准备成本，突出 RIMS 价值。
3.  **1 套数据贯穿全链路**：CRM_V1（含 `CUSTOMER_ORDER` 头、`ORDER_LINE` 行、`ORDER_ATTACHMENTS` 附件）即可覆盖所有场景，无需多系统。
4.  **可录制、可回放**：每个功能均有明确输入/输出/产出物，便于领导事后复盘。

## 四、AI / 人工分工总览图

```text
            人工决策 (30%)                         AI 自动化 (70%)
   ┌──────────────────────────┐        ┌──────────────────────────────────┐
   │ ① 连库/选表/映射确认      │───────▶│  探测/推荐/校验/写入/进度         │ 迁移
   │ ② 别名/控件/敏感标记     │───────▶│  JSON 生成/驱动前端渲染          │ 元数据
   │ ③ 选系统/输关键词/时间   │───────▶│  SQL 生成/掩码/分页               │ 搜索
   │ ④ 配置外键/展示列        │───────▶│  主子联动查询/格式化              │ 列表
   │ ⑤ 点击预览               │───────▶│  鉴权/SAS 签发/审计               │ 附件
   │ ⑥ 设保留期/确认销毁     │───────▶│  到期计算/扫描/清单               │ 删除
   │ ⑦ 筛选/导出               │───────▶│  埋点/聚合                        │ 日志
   └──────────────────────────┘        └──────────────────────────────────┘
                    领导视角：一线操作“点一下”，后台 AI 已做完“十步”
```

| 维度 | AI 占比 | 典型 AI 产出物 | 人工输入成本 |
|------|---------|----------------|--------------|
| 数据接入 | 75% | 探测报告、映射建议、校验报告 | 1 次连接 + 1 次确认 |
| 治理配置 | 70% | Schema JSON、标签建议 | 点选确认 |
| 查询利用 | 80% | 动态表单/SQL/脱敏结果 | 输入 2 个条件 |
| 安全合规 | 85% | SAS、掩码、审计日志 | 点击触发 |
| 生命周期 | 65% | 到期清单、风险提示 | 审批确认 |

## 七、风险与建议（领导关切）

| 风险 | 影响 | 应对（Demo 版） | 正式版演进 |
|------|------|------------------|------------|
| 真实 Azure/Databricks 未就绪 | 无法演示 | 用 H2 + 内存掩码 + MinIO 模拟，接口不变，后续替换为真实 SDK | Phase2 切真实 ADLS/UC |
| 一对多关联查询慢 | 演示卡顿 | Mock 数据 500 行，P95 <1s；正式 TB 级需分片与索引 | 引入物化视图 |
| 敏感数据现场泄露 | 合规风险 | 演示数据全脱敏样本，掩码固定 `***` | 对接真实 UC Mask |
| 领导追问 AI 边界 | 解释不清 | 本表已明确 AI/人工分工，可答“AI 做 70% 重复，人工做 30% 决策” | Phase3 引入 AI 解析/语义检索 |

**建议**：本次 Demo 聚焦 **P0 7 项**，2 天可 ready；P1 3 项作为“彩蛋”按需展示。演示后可直接沿用该环境进入 Sprint 1 开发。
